# Project - AI Workspace

A simple and modern **AI Workspace landing page** created using **HTML, CSS, JavaScript, and Tailwind CSS**.

The website provides a clean workspace interface where users can write, plan, share, and collaborate with AI.

## 🚀 Features

* Responsive navigation bar
* Hero section with heading and description
* "Get AI Free" button
* "Request a Demo" button
* Dashboard workspace design
* Custom dashboard image section
* Task, project status, and team activity cards
* Project progress bar
* Floating information cards
* Floating chat button
* JavaScript alert functionality
* Mobile responsive design
* Tailwind CSS CDN included

## ▶️ How to Run

1. Download or copy the project folder.
2. Open the project in **VS Code**.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Put your image inside the `assets` folder.
5. Open `index.html` in a web browser.

You can also use the **Live Server** extension in VS Code.

## 📱 Responsive Design

The website is responsive and adjusts its layout for smaller screens.

On mobile devices:

* Navigation links are hidden
* Hero heading becomes smaller
* Buttons are displayed vertically
* Sidebar is hidden
* Dashboard cards become vertical
* Floating cards are hidden
* Dashboard image adjusts to screen size
